# Phase 7 execution plan

Date: 2026-08-24. Starting tracked commit: `7a02e9d4d01ff68c472f21fa1d1ccca929327fc4`. Branch: `product/runtime-snapshot-probe-foundation`. Safety tag: `phase-6-desktop-productization-handoff-2026-08-24`. Eight pre-existing untracked Phase 5 screenshot aliases remain outside this work.

1. **Source Identity v2** — retain Git HEAD/ref/worktree identity when present and add deterministic snapshot/parent/Episode identity when Git is absent. New Episodes map into existing `ProjectChange` records; old identities remain valid and immutable.
2. **Runtime Profiles** — migration `0007_runtime_snapshot_probe_foundation` adds versioned multi-runtime profiles, detections and bounded instances. One typed adapter registry supports Python, Node, PHP, generic process and metadata-only Ruby/Java detection; execution is executable-plus-argv, approval-gated, shell-free and fail-open.
3. **Snapshot memory** — add an external content-addressed SHA-256 object/manifests store below the MellowYak data root with atomic publication, deterministic manifests, sensitive/large/ignored/symlink exclusions, deduplication, integrity checks, safe materialization and reference-safe retention.
4. **Episodes** — coalesce bounded watcher events using debounce, settle and maximum-duration rules. A stable Episode creates at most one snapshot; an identical manifest reuses the prior snapshot while preserving Episode history. Watcher/adapter failure never blocks project writes.
5. **Probes and milestones** — version Browser, loopback HTTP, CLI, Process, Test and Manual probes behind one runner contract. Runs bind to exact source/runtime identities, enforce timeout/cancellation/retry, retain bounded evidence and feed the existing Protection Plan/regression path. A Save Point alone is not a behavioral baseline; “This works — save it” requires a passing probe or explicit human attestation.
6. **Signals** — deterministic `WATCH`, `SUSPECTED`, `HIGH`, `CONFIRMED` reasons supplement rather than replace the Completion Gate. File/impact changes alone remain `WATCH`; only reproducible comparable prior-PASS/current-FAIL evidence or an existing supported regression decision becomes `CONFIRMED`.
7. **Repair Workspace v1** — materialize a selected current snapshot under the local data root, outside live source, with redacted incident/validation/instruction manifests and open/copy/delete actions. Phase 7 never applies changes to live source and has no coding-agent connector.
8. **Desktop product** — replace Add Project with a concise translated Runtime Wizard; add Runtime and Memory project views, actionable Ready-with-limits details, Save Points, probe setup, known-good and repair-workspace surfaces. English remains the base catalog and Hebrew remains complete RTL; every visible string is a translation key.
9. **Verification and delivery** — deterministic Python/Node/PHP/polyglot/non-Git/PulsePlan fixtures cover security, migration, CAS, Episodes, adapters, probes, signals and repair isolation. Final gates include full Python/React, TypeScript/Vite, translation checker, Ruff, Cargo, deterministic OpenAPI, packaged engine, fresh Intel macOS app/DMG and packaged Phase 7 flows.
10. **Exclusions** — no Codex/Claude/Cursor/VS Code/MCP integration, prompt/provider credential access, cloud upload, automatic repair/apply, live-tree mutation, production deployment/rollback, accounts, billing, signing, notarization or public release.
