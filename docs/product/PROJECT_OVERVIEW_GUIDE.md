# Project Overview guide

Project Overview is a bounded evidence summary for exactly one registered project.

- **Source** shows current identity and availability, not a promise that every file is understood.
- **Latest Episode** links the most recent grouped local change and its current signal.
- **Checks** separates required, suggested, skipped, unknown and unavailable work.
- **Behaviors** shows protected expectations and their latest accepted/current evidence.
- **Regressions** lists only evidence-supported incidents; impact alone cannot create one.
- **Runtime and storage** show operational readiness, activity mode and relevant limitations.

`Healthy` or `No confirmed issue` is bounded by available evidence. `Ready with limits` requires the
limitations to remain visible. `Unknown`, stale, unavailable or missing evidence must never be turned
green. Use the next-action link to reach the exact Episode, regression, runtime setup, disconnected
source or recovery item.

Technical detail is intentionally progressive. Paths, hashes, entity IDs and deterministic reason
codes render only under disclosure and remain left-to-right in both English and Hebrew.
