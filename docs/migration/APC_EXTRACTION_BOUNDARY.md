# APC extraction boundary

MellowYak is a clean product, not a renamed APC deployment. The APC repository is read-only evidence. Phase 1 copies no APC runtime or business logic.

## Eligible for selective reuse

Later phases may port independently reviewable contracts, algorithms, fixtures and lessons from verified Browser Runtime infrastructure, Project MAP source signatures/correlation, source-map-first discovery, Completion Capsule idempotency and proof, and Verified Memory lineage/hash/versioning. Every imported fragment must record exact APC source path, observed status, decision, security review, destination and tests.

## Must be rewritten

The old Bridge becomes functionality inside a loopback-only managed Local Engine. Storage, process transport, connector interfaces, evidence metadata, source/runtime graphs, restore and completion imports must be implemented against local-first typed contracts. Connectors describe external model/tool communication; execution arms perform bounded actions. They remain separate and opt-in.

## Historical reference only

APC UI pages, server workflows, reports and experimental context systems may explain lessons but are not product foundations. Cognitive Optimizer, Semantic Codec, Screenshot Memory and Tool/Pattern/Memory/QA sidecar claims stay frozen until reproducible evidence exists.

## Prohibited

No PHP control plane, MariaDB schema, Docker/server topology, tenant/user/role system, host control, old backup topology, generated artifacts, binaries, dependencies or legacy pages may enter the local core. `_codex_read.php`, `model_context.php`, and installation-token-wide semantics from `api/model.php` and `api/ingest.php` are security blocked and must not be copied or adapted.

## Security debt left behind

MellowYak intentionally leaves behind broad source-reading routes, installation-wide tokens, public/listener assumptions, privileged host controls, centralized telemetry, server credentials and cross-tenant complexity. Future APC-derived work requires a fresh threat review; historical existence never grants approval.
