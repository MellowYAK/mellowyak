# Phase 7 portable delivery

This folder is the portable handoff for **Phase 7 — Runtime Profiles, Snapshot Memory, and Universal
Probes**.

- `PHASE_7_IMPLEMENTATION_REPORT.md` — architecture, product surface, security boundaries, and honest
  limitations.
- `VERIFICATION_EVIDENCE.md` — exact final-gate and fresh-package evidence.
- `PHASE_7_SCREEN_GUIDE.md`, `.html`, and `.pdf` — the 23-screen explained visual review.
- `PHASE_7_SCREENSHOT_MANIFEST.json` — machine-readable screenshot provenance and expectations.
- `APC_EXTRACTION_NOTE.md` — read-only provenance and the boundary between APC and MellowYak.
- `RESEARCH_SOURCE_SUMMARY.md` — bounded official sources and the decisions they informed.
- `screenshots/` — 23 deterministic synthetic-data PNGs only; no user paths, source, credentials,
  or private project data.

[`../validation/PHASE_7_RUNTIME_MEMORY_PROBE_VALIDATION_REPORT.md`](../validation/PHASE_7_RUNTIME_MEMORY_PROBE_VALIDATION_REPORT.md).
