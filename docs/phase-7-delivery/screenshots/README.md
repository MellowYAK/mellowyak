# Phase 7 screenshot source policy

Only deterministic synthetic public fixture data may appear in this directory. Images must contain
no real user path, repository source, credential, token, cookie, private host, browser session, APC
data, snapshot object, evidence bundle, runtime log, or Repair Workspace content.

The 23 required filenames and seven-field explanations are indexed in
[`../PHASE_7_SCREEN_GUIDE.md`](../PHASE_7_SCREEN_GUIDE.md). They were captured by
`scripts/capture_phase7_delivery.mjs` with the authenticated loopback API boundary replaced by a
deterministic synthetic fixture. The companion HTML, 24-page PDF, and JSON manifest are in the
parent delivery folder.
