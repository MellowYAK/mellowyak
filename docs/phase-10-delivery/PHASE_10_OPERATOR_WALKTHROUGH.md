# Phase 10 operator walkthrough

Use a disposable repository or Demo Lab. Do not use a private project for the first review.

1. Launch MellowYak and complete First Run with keyboard and pointer. Confirm Continue is disabled
   until one option is selected and that background preferences persist.
2. Open Home. Confirm empty state offers Add Project, then create Demo Lab and confirm the project row
   appears without a fabricated green guarantee.
3. Open Project Overview. Review source, latest Episode, checks, behaviors, regression, runtime,
   storage, limitations and next action.
4. Open Activity and an Episode. Confirm chronological facts, skipped/unknown checks and technical
   disclosure remain tied to the selected project.
5. In Demo Lab, accept known good, inject the synthetic regression and open Regression Detail. Compare
   prior PASS, current/retry FAIL and exact reason details.
6. Open the Repair Workspace. Create the bad candidate and verify rejection; create the valid
   candidate and verify workspace validation. Confirm live source has not changed yet.
7. Open Apply. Ensure confirmation is initially unselected. Confirm only deliberately; observe
   Safety Snapshot, journal, write and fresh live verification.
8. Run the simulated post-check failure and confirm rollback reports restored paths and byte identity.
9. Open Disconnected Projects and inspect identity preview/mismatch choices. Do not force a mismatch;
   reconnect/relocate must not move source.
10. Open Diagnostics. Refresh, run Product Self-Test, inspect executed steps, create a support bundle
    and review included/excluded data before revealing it.
11. Check updater and activity-mode states. Battery Saver may defer noncritical work but must retain
    identity, integrity, critical alerts, recovery, verification and Apply safety.
12. Switch to Hebrew and inspect Home, Overview, Regression and Diagnostics for RTL, meaningful copy,
    visible focus and LTR technical tokens.
13. Close the window, reopen from the native tray, then Quit. Confirm no desktop/engine process remains.

Record platform, architecture, version, exact commit and any mismatch. A manual observation is not a
cross-platform certification or proof of a production updater.
